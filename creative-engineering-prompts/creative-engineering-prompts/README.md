# Prompt library

Extract into your project root, open Claude Code and ask it to read CLAUDE.md and MASTER_PROMPT.md. Execute modules in listed order; stop at failing checks. Foundation precedes UI. Supply your own media, career data and contact configuration.

## Scope
Public page text and visible controls were inspected. Exact visual styles, runtime interactions, original source and conversation history were not verified. Gold colors, timing, breakpoints and proposed architecture are new design choices.
